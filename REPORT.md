# REPORT — збірка лендингу Iskra

Дата: 2026-11-17. Джерело вимог: SPEC «Iskra: технічне завдання для AI-агента» (Claude Doc) і PRD.

## Що зроблено
- `site/` — готовий статичний сайт: `index.html`, `styles.css`, `sky.js`, `data/sky.json`, шрифти, лого/фавікони/OG, `robots.txt`, `sitemap.xml`, `.htaccess`, `CREDITS.txt`.
- `scripts/build-stars.mjs` — дані зірок із d3-celestial (5044 зірки до 6m, 123 КБ), перевірки структури та саніті-тест (Полярна, Вега).
- `scripts/copy-assets.mjs`, `scripts/zip.mjs` → `dist/iskra-site.zip` (316 КБ).
- `tests/site.spec.mjs` (7 в'юпортів + поведінка), `tests/perf.spec.mjs` (анімація під 4× сповільненням CPU). Скріншоти — `tests/screenshots/`.
- `DEPLOY.md` — кроки для HostiQ.

Підібрано перебором: на 1366×768 і 1920×1080 видно всі 6 сузір'їв, а кути екрана не далі 115° від полюса (інакше стереографічна проекція робить край неба порожнім). На портретних телефонах повністю видно 4 сузір'я.

## Результати
- `npm test`: **13/13 пройдено** (тексти дослівно, кнопка, перший екран, без горизонтальної прокрутки, сузір'я, reduced-motion, без JS, Tab-фокус, трекінг кліку, бюджети розмірів, анімація).
- Анімація, 1366×768, 4× CPU: медіана й p90 інтервалу кадру — 16,7 мс (60 fps).
- Перше завантаження: 189 КБ + лого (бюджет 500 КБ). HTML+CSS+JS — 27 КБ (бюджет 60 КБ).
- Lighthouse (мобільний, локально, headless Chromium): Accessibility 100, Best Practices 100, SEO 100, LCP 2,3 с, CLS 0. **Performance — 69–89, від запуску до запуску.** На цій машині TBT дуже шумний. Той самий сайт із заблокованим `sky.js` дає 73–78, порожня HTML-сторінка — 99. Більшість TBT складають задачі, які браузер не приписує жодному скрипту (програмний рендеринг у headless-режимі). Остаточну оцінку варто взяти з PageSpeed Insights після деплою.

## Відхилення від SPEC
- Небо запускається після `load` і в режимі простою браузера. Шар зірок будується шматками по ~8 мс, а повернутий фон кешується й перемальовується, коли зсув сягає ~1 px. Мета — зменшити TBT і навантаження на CPU.
- На малих екранах (min(W,H) < 600) небо не обертається, бо майже повністю закрите текстом. Мерехтіння й метеори працюють.
- Затемнення під текстом — фіксоване на весь екран (`position: fixed`), а не `inset: -10% -30%`: старий варіант додавав прокрутку.
- На низьких телефонних екранах (≤ 600 px заввишки) шрифти й відступи менші, щоб кнопка вміщалася в перший екран на 320×568.
- `archiver` v8 імпортується як `{ ZipArchive }`.

## Плейсхолдери, які треба замінити
- `__FORM_URL__` у `site/index.html` — посилання на Google Форму (`npm run zip` без нього не пакує).

## Відкрите (рішення власника)
- Аналітика: підключено лише адаптер `track('cta_click')`, сервіс не вибрано.
- Контакт для запитів на видалення даних: текст політики обіцяє видалення на запит, але адреси для таких запитів на сторінці немає.
- Посилання на соцмережі — не додавались.
- Локальної копії SPEC у `prd/` немає: її можна експортувати з Claude Doc як Markdown.
