# Деплой Iskra на HostiQ

## 1. Вставити посилання на Google Форму
1. Відкрийте `site/index.html` і знайдіть `__FORM_URL__` (одне місце, у кнопці `#cta`).
2. Замініть його на посилання з форми (кнопка «Надіслати» → посилання, напр. `https://forms.gle/...`).
3. Перевірте й зберіть архів:
   ```
   npm test
   npm run zip
   ```
   Архів: `dist/iskra-site.zip`. Поки в сайті є `__FORM_URL__`, `npm run zip` відмовиться пакувати; для тестової збірки є `npm run zip -- --allow-placeholder`.

## 2. Домен і SSL
1. У панелі HostiQ переконайтеся, що домен `iskra-project.com.ua` прив'язаний до хостингу (NS-сервери HostiQ або A-запис на IP хостингу).
2. Увімкніть безкоштовний SSL (Let's Encrypt) для `iskra-project.com.ua` і `www.iskra-project.com.ua`.

## 3. Завантаження
1. Файловий менеджер → `public_html`.
2. Видаліть стандартний `index.html` хостингу (якщо є).
3. Завантажте `iskra-site.zip`, розпакуйте його прямо в `public_html`, архів видаліть.
4. Переконайтеся, що файл `.htaccess` на місці (він прихований; у файловому менеджері ввімкніть показ прихованих файлів).

## 4. Перевірка після запуску
- `http://iskra-project.com.ua`, `http://www.…` і `https://www.…` відкривають `https://iskra-project.com.ua/`.
- Кнопка «Зв'язатися з нами» відкриває форму в новій вкладці; тестова заявка з'являється в Google Таблиці, приходить лист.
- PageSpeed Insights (мобільний): https://pagespeed.web.dev/ — ціль Performance ≥ 90.
- Надішліть посилання собі в Telegram — має показатися прев'ю з логотипом.

## Оновлення сайту
Змінили щось у `site/` → `npm test` → `npm run zip` → завантажте й розпакуйте архів у `public_html` поверх старих файлів.
